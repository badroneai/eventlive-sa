# Package 06 — Live Observation

هذه حزمة إضافية مستقلة فوق خط أساس Package 05. لا تعدل Package 03/03A/03B/03C أو Package 04 أو EventLive.

تبدأ الحملة بالسؤال المؤجل `P04-003` ثم 29 خلية P05 فريدة موزعة على 24 مجالًا. تستخدم هوية DataSaudi نفسها المستخرجة من دليل سابق، وتحفظ البصمة فقط. تتوقف عند أول رسالة حصة صريحة، ولا تعيد السؤال ولا تنشئ هوية بديلة.

الرصد الحي ليس حكم صحة. كل جواب يمر لاحقًا عبر adjudication مستقل، وتبقى أرقام P05 الأساسية ثابتة.
