# DataSaudi Package 04 — Live Universe Exploration Methodology

## القرار المنهجي

سجل Package 03C أغلق 267/267 سؤالًا معرفيًا بصورة مستقلة، لكنه لا يثبت استنفاد قدرات INSAIGHTS الحية. المنهج الأصلي يستهدف 2,304 تشغيلات؛ لذلك تمثل الأسئلة المجمدة 267/2,304 = 11.59%، بينما تمثل المشاهدات الحية 49/2,304 = 2.13% فقط.

تنتقل Package 04 من شبكة الأسئلة الأفقية العامة إلى **اختبارات عمودية عالية العائد المعلوماتي**. كل سؤال في `prompts.jsonl` يختبر آلية محددة قابلة للتفنيد ضد API والكتالوج، ولا يعيد أسئلة availability/direct/series/rank/cross/derive/explain/limit السابقة.

## الأدوار

- **مدير البحث:** يملك المقام وترتيب الأسئلة حسب العائد المعلوماتي ويحمي حصة الرسائل.
- **معماري OLAP والكتالوج:** يراجع cube/dimension/hierarchy/level/member/measure وعقود الاستعلام.
- **خبير الإحصاء الاقتصادي السعودي:** يضبط دلالات stock/flow/index/rate، سنة الأساس، والتجميع الزمني.
- **مهندس جودة البيانات:** يفصل بين empty وnull وzero وno-time وHTTP error وnot-found.
- **خبير الربط والتصنيفات:** يراجع الجغرافيا وISIC وHS2 والـcrosswalks وأدق grain مشترك.
- **Red Team للنماذج:** يختبر الشمول الزائف، fallback الصامت، والرفض الجزئي.
- **أمين الأدلة وprovenance:** يحفظ raw frames والروابط والتوقيتات والـhashes قبل التفسير.
- **مدقق العربية والإنجليزية:** يقارن member keys والقيم أولًا ثم captions المترجمة.

## لماذا هذه الدفعة؟

تغطي الأدلة المحلية 277 مكعبًا و722 بُعدًا و753 هرمية و992 مستوى و479 مقياسًا. كما تكشف سطحًا غير مختبر حيًا: مكعبات مخفية في الواجهة، فروق `show_all`، أعضاء مستبعدة، أخطاء member endpoints، مكعبات بلا زمن، مكعب موجود بلا صفوف، فجوات المصدر، ومرشحات crosswalk تحتاج مراجعة.

توزيع الدفعة الأولى:

- `P04-001..006`: الكتالوج وسطح الوصول.
- `P04-007..011`: schema والأعضاء والهرميات.
- `P04-012..016`: الزمن والمراجعات واكتمال السلاسل.
- `P04-017..021`: الجغرافيا والتصنيفات والربط.
- `P04-022..026`: الحسابات والمصالحة.
- `P04-027..030`: provenance والرفض الجزئي والتكافؤ اللغوي.

## بروتوكول التنفيذ

1. لا يُهدر سؤال مستقل لفحص إعادة ضبط الحصة؛ يكون `P04-001` أول اختبار ذي قيمة. إذا ظهر quota frame يتوقف التنفيذ فورًا.
2. تُستخدم الهوية والحصة نفسهما. لا تدوير هوية ولا تحايل على الجلسات.
3. قبل تفسير كل جواب تحفظ الحقول التالية: prompt SHA، session/run IDs، وقت الإرسال، أول frame، النهاية، raw WebSocket frames، النص الخام، citations، terminal reason، وlatency.
4. يفكك الجواب إلى ادعاءات من الأنواع: `SCHEMA_METADATA`, `RAW_DATA_ROW`, `CALCULATION`, `INFERENCE`, `LIMITATION`.
5. يعاد تشغيل كل رابط بيانات بصورة مستقلة، ويحفظ response hash وsource-row hash. لا يعدل transcript الخام بعد التحكيم.
6. كل ادعاء يستخدم «كل»، «لا يوجد»، أو «أحدث» يحتاج مقامًا مثبتًا أو بحثًا كاملًا، وإلا يصنف شمولًا زائفًا.
7. عند quota/auth/contract block تحفظ الأدلة ويتوقف الإرسال؛ لا تستهلك الحصة بإعادة السؤال.
8. ينفذ زوج التكافؤ `P04-029` و`P04-030` في سياقين نظيفين إن كانت الواجهة تتيح ذلك، مع الحساب والحصة نفسهما، ويسجل ترتيب التنفيذ.

## معادلة العائد المعلوماتي

يختار السؤال وفق المعادلة التشغيلية التالية:

`IG = 30% uncertainty + 25% downstream leverage + 20% falsifiability + 15% surface breadth + 10% quota efficiency`

حصلت أسئلة الدفعة على 5/5 لأنها تكشف طبقة كاملة، أو تفصل حالات خطرة، أو تنتج حقيقة قابلة لإعادة التشغيل من دليل رسمي.

## بوابات الحملة

- **Capture Gate:** لكل سؤال raw evidence غير قابل للتعديل أو block صريح.
- **Replay Gate:** لكل ادعاء رقمي query/row hash أو يسقط الادعاء.
- **Semantic Gate:** الوحدة والزمن والجغرافيا والمقام وstock/flow صحيحة.
- **Refusal Gate:** لا cube أو member أو value أو source مختلق.
- **Parity Gate:** الزوج العربي/الإنجليزي يطابق keys والقيم والفترات، مع السماح باختلاف captions فقط.
- **Coverage Gate:** تقاس capability cells الجديدة، لا عدد الأسئلة فقط.

## توليد الدفعة التالية

لا تكتب الدفعة التالية مسبقًا بصورة عشوائية. تشتق من نتائج هذه الدفعة:

- إذا فشل تعداد الكتالوج ونجحت schemas الفردية، يجزأ التعداد حسب source/topic.
- إذا كانت المكعبات المخفية قابلة للاسترجاع، تؤخذ عينة طبقية من جميع المكعبات المخفية.
- إذا أخفى المساعد أخطاء members، تتوسع الحملة إلى مستويات الخطأ المعروفة وتقيس honesty rate.
- إذا غابت crosswalks الصريحة، يوقف أي تحليل يعتمد الربط ويبنى mapping audit أولًا.
- إذا نجحت الحسابات، تنتقل الحملة إلى multi-cube reconciliation؛ وإذا أخفقت تضاعف اختبارات الحساب العدائية.
- إذا ظهر اختلاف عربي/إنجليزي، تبنى parity matrix عبر الزمن والجغرافيا والتصنيفات.

## حد التفسير

نجاح ثلاثين سؤالًا لا يعني استنفاد الكون. هذه أول دورة active learning بعد Package 03C، وتغلق فقط عندما تصبح نتائج كل قدرة قابلة لإعادة التشغيل، أو يكون حد المنصة موثقًا دون تحايل.
