# EventLive Organizer Guide

EventLive gives organizers a public live reference for events, workshops, conferences, and programs.

## Organizer Paths

| Need | Page | Success |
| --- | --- | --- |
| Understand the offer | `/organizers.html` | Organizer understands live schedules, source evidence, and event-day use. |
| Submit or improve an event | `/organizer-intake.html` | Organizer provides event URL, city, date, source, image, and schedule evidence. |
| Correct a page | `hello@eventme.live` | EventLive can update date, venue, image, source, or schedule details. |

## Publication Requirements

- Event title.
- Start date or attendance window.
- City or online attendance mode.
- Official or approved source URL.
- Venue, image, and session schedule when available.

Discovery-only sources are used as signals, not direct publishing authority.
