# EventLive Visitor Guide

EventLive helps visitors decide what to attend now, next, and later across Saudi events.

## Primary Paths

| Need | Page | Success |
| --- | --- | --- |
| Discover events | `/index.html` then `/events.html` | Visitor finds an event by title, city, category, audience, or status. |
| Attend today | `/today-events.html` | Visitor sees what is live or soon and opens details/calendar. |
| Use venue screen | `/screen.html` | Visitor sees the nearest live schedule and scans QR for mobile follow-up. |
| Trust a listing | Event detail page | Visitor sees date, city, venue, source, calendar file, and live schedule when available. |

## Visitor Principles

- Dates and countdowns are rendered in Asia/Riyadh.
- Ended events remain normal event records with their original dates.
- EventLive is a reference layer; ticketing and final attendance conditions belong to the official organizer/source.
